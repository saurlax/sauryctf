# 题目附件

附件的权威内容保存在 S3 兼容对象存储，本地磁盘只用于受限临时处理。`content_objects` 保存随机对象键、SHA-256、大小、媒体类型和状态；`content_references` 决定题目、Writeup 和导出包授权。

上传先进入临时对象，通过大小、媒体类型和摘要校验后再提交为不可变对象。未提交且无引用的临时上传默认 24 小时回收；共享引用存在时不得删除底层对象。

题库版本引用附件，挂题时复制到比赛题目快照。模板后续更新不会覆盖已发布比赛的附件引用。选手下载必须经过 Nuxt 控制面重新校验比赛发布状态、参赛资格、题目发布时间和对象引用，然后返回短期签名 URL 或受控流。私有内容、Writeup 和危险媒体类型必须使用正确权限与 `Content-Disposition`。

比赛包导入在隔离目录限制条目数、解压大小、压缩比、路径和摘要；导出使用版本化清单并保持对象不可变。对象存储不可用时不能回退到某个控制面副本的本地附件目录。
