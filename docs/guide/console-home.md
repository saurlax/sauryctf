# 控制台首页

`/console` 是已登录用户的入口，展示账号安全状态、当前队伍和可继续处理的比赛操作。它只通过 Nuxt 同源 API 读取服务端投影，不保存角色或业务事实。

优先动作按服务端状态决定：

- 默认管理员或未完成账号要求：进入 `/console/account` 改密、设置并验证邮箱；
- 未组队用户：进入 `/console/team` 创建或加入队伍；
- 已组队用户：打开比赛列表或已报名比赛；
- 队长：管理邀请码和成员，但接受参赛后普通成员变更会被锁定；
- organizer/admin：显示管理入口；只有 admin 显示用户、平台设置和全局运维入口。

所有失败 toast 使用 API 安全错误消息，不能显示堆栈、SQL 或内部响应。控制台摘要仅用于导航；报名、提交、实例和管理写操作仍由对应领域服务重新授权。
