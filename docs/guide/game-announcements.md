# 比赛公告

organizer/admin 可以为比赛创建公告草稿、设置发布时间、修改未撤回公告或执行撤回。管理接口位于 `/api/admin/contests/{contestId}/announcements/**`，选手通过 `/api/contests/{contestId}/announcements` 读取当前可见公告。

未到 `publish_at` 的公告不可见。发布事务写公告事实和唯一 Outbox 事件；重复调度或重试不能产生重复公共事件。公告发布、修改和撤回都记录操作者与审计。

公共时间线只展示已经发布的公告以及规范允许的题目/提示发布、首解、封榜和阶段变化。报名审核、实例运维、安全事件和管理修改不得混入公共时间线。公告内容使用其原始单语字段，界面语言切换不会自动翻译或改写内容。
