# 比赛邀请码

私有比赛可以要求报名邀请码。邀请码属于比赛报名约束，只在 organizer/admin 的管理投影中可见；公开比赛投影、错误响应、日志、缓存和时间线不得返回明文邀请码。

报名时，Nuxt 控制面在 PostgreSQL 事务中校验邀请码和其他参赛条件。人工审核制比赛在接受时还会重新检查邀请码要求、邮箱状态、队伍人数、允许邮箱域和比赛阶段，不能只依赖报名发起时的结果。

错误或缺失的邀请码返回稳定、不可枚举的报名失败，不说明某个值是否曾经有效。更新比赛邀请码属于管理写操作，需要版本前置条件或幂等保护并写不可变审计；已接受参赛记录不会因后续轮换被静默撤销。

队伍邀请码是另一套凭证，仅用于加入队伍，可由队长轮换。两种邀请码不得复用字段、日志或缓存 key。
